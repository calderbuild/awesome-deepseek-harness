# Contributing

I keep this list small and verifiable. Before opening a pull request:

- One addition per PR. Grouping a few closely related links is fine, but keep the change readable.
- The link must exist and be reachable when the PR is opened.
- The description is one sentence, factual, and does not repeat the project name.
- Plugins go under Community plugins and should be discoverable through the `dsh-plugin` topic or clearly dsh-specific.
- No promotional listings for unrelated products, no affiliate links.

If a link rots or a project is abandoned, open an issue or PR to remove it rather than leaving a dead entry.
